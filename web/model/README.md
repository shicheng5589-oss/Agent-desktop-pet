## 相关约定

* `settings.json` 是本桌宠实际读取的模型入口（Live2D 的 `*.model3.json` 格式）。
* `c_0120.vtube.json`、`items_pinned_to_model.json`、`prop_expressions.json`、`c_0120.model3.json`
  等是 VTube Studio 的工程文件，程序不读取，可自行决定留删。
* 想把桌宠换成你自己的模型：把 Cubism 4（`.moc3`）模型放进本目录并改 `settings.json`，
  详见根目录 [README](../../README.md) 的「换成你自己的 Live2D 模型」。
