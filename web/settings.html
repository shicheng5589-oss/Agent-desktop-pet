Agent 桌宠

形象会跟着接入 Agent 的实时状态变化：思考 / 执行 / 等待 / 完成…

桌宠此刻：—

外观

Agent

接入的 Agent（进度卡片、表情、用量都跟着它走）

统计 token 需要读取本地会话记录，修改后点「保存并应用」生效；保存后可能需要几秒到最多约 20 秒才会刷新，属正常现象。

卡片

底部按钮与功能方案

撤回 / 铅笔 / 橡皮擦 支持独立配置：每个按钮的单击、右键都可选择功能。 每次触发都会先弹出「确认 / 取消」，确认后才执行；任何一项都能选「无功能」。

状态对应的表情

模型里一共找到 0 个表情，按喜好改就行，改完立即生效。

表情白名单

不想要的表情（比如那些"道具 / 贴纸"类，像 晕晕、吐魂、各种贴纸） 在这里取消勾选，就再也不会出现了；状态映射和随机心情都会跳过它们。

动作与表情播放

模型里有 0 个动作、0 个表情。 动作若一直循环（比如那段 4 秒的闲置表演），可以把它们单独关掉。

排查

WebView2 缓存：— · 「清空日志」只清文本日志（pet.log）；「清除缓存」清浏览器缓存（.webview2，通常 200–400MB），清完会自动重启，首次加载稍慢。

桌面快捷方式：— · 首次启动会自动创建一个；不喜欢就点按钮删掉（删掉后不会再自动出现），需要时用按钮或文件夹里的「创建桌面快捷方式.cmd」重建。
